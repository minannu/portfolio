ICFNet: An Incongruence-Aware Cross-Modal Unified Framework for YouTube Clickbait Detection with Multimodal LLM Comparison

Revision Submitted

Information Processing & Management

Md. Minhazul Islam, Md. Masum Mia, Amith Khandakar, Mohamed Arselene Ayari, Md. Tajim An Noor, Muhammad Salman Khan, Hamed Noori

ICFNet detects YouTube clickbait by modeling incongruence between titles and thumbnails. It fuses RoBERTa and ConvNeXtV2 features via bidirectional cross-attention and an incongruence-aware FiLM-gated classifier. On YTClickbait21K (21,238 videos), it reaches 92.04% accuracy and 97.51% AUC while training only 3.02M parameters with frozen backbones, with cross-dataset, retrieval-augmented LLM, and explainability analyses.

Multimodal Learning Clickbait Detection LLM Comparison

Encoder–Encoder Cross Attention Based Contextual Sarcasm Detection

Under Review

Journal of Big Data

Md. Minhazul Islam, Md Tanbeer Jubaer, Md. Azmain Yakin Srizon, Saad Aloteibi, Mohammad Ali Moni

A contextual encoder–encoder cross-attention framework for sarcasm detection in social media conversations. Jointly models Reddit parent comments and replies, introduces sarcasm-adaptive ELECTRA pretraining via Replaced Token Detection on SARC V1, and reaches up to 83.72% accuracy. Ablations confirm the value of both cross-attention and domain-specific pretraining. Based on undergraduate thesis research.

Sarcasm Detection Cross-Attention ELECTRA

Unified Privacy Score: A Multi-Dimensional Framework for Attack-Aware Privacy and Utility Evaluation

Under Review

IEEE Transactions on Information Forensics and Security

Amith Khandakar, David G. Michelson, Md Minhazul Islam, Md Masum Mia, Mohamed Arselene Ayari, Khaled Khan

Introduces the Unified Privacy Score (UPS), integrating syntactic, semantic, information-theoretic, and adversarial-resilience privacy dimensions for structured data release. Evaluates 11 anonymization methods with 16 privacy attacks and four utility metrics, enabling clearer privacy–utility comparisons for privacy-preserving data publishing.
